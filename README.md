# 🚌 셔틀버스 정산 자동화 시스템

신세계면세점 협력사원 셔틀버스 탑승 기록을 업로드하면, 운영사별 탑승 인원을 집계해 협력사별 지원금액을 자동으로 산출하고 정산 엑셀을 생성하는 Streamlit 앱.

1인당 지원금액을 매월 입력값으로 받으므로, 단가가 바뀌어도 코드 수정 없이 바로 정산할 수 있음.

---

## 주요 기능

- 1인당 지원금액 직접 입력 (기본값 41,935원)
- CSV·엑셀(.xlsx) 탑승 기록 업로드
- 운영사별 탑승 인원 자동 피벗 집계
- 협력사별 지원금액·총계 자동 산출
- 화면 미리보기 후 정산 엑셀(2시트) 다운로드

---

## 입력 파일 양식

CSV 또는 엑셀(`.xlsx`) **한 개**. 아래 **6개 컬럼**이 모두 있어야 하며, 컬럼명은 정확히 일치해야 함.

| 컬럼 | 설명 |
|---|---|
| `운영사` | 셔틀 운영사명 (예: 스위스관광 / 신백승여행사) |
| `태그ID` | 탑승자 식별값 (중복 제거 기준) |
| `탑승자` | 탑승자명 |
| `협력회사명` | 소속 협력사명 |
| `사업자등록번호` | 협력사 사업자등록번호 |
| `기업규모` | 협력사 기업규모 |

> ⚠️ **주의 1 — 운영사명 표기 일관성**
> 현재 정산 합산 로직은 운영사 `스위스관광`·`신백승여행사`를 기준으로 동작함.
> 운영사명이 `스위스 관광`처럼 공백·표기가 흔들리거나, **신규 운영사가 추가되면
> 해당 인원이 총인원·지원금액 합계에서 누락될 수 있음.** 운영사명은 매월 동일하게 유지.

> ⚠️ **주의 2 — CSV 인코딩**
> 국내 엑셀에서 "CSV로 저장" 시 `cp949(euc-kr)`로 떨어지는 경우가 많음.
> 한글이 깨지거나 업로드 오류가 나면 `UTF-8`로 다시 저장하거나 `.xlsx`로 업로드.

> ⚠️ **주의 3 — 태그ID 의미**
> `태그ID`는 탑승자 고유 식별값이어야 함. 매 탑승마다 바뀌는 값이면 중복 제거가
> 되지 않아 인원이 과대 집계됨.

## 출력 결과

다운로드되는 `셔틀버스_정산_완료.xlsx`는 2개 시트로 구성됨.

| 시트명 | 내용 |
|---|---|
| `실제_탑승인원_명단` | 중복 제거된 고유 탑승자 명단 |
| `협력사별_지원금액_총계` | 협력사별 운영사 인원·지원금액 + 총계 행 |

정산 시트 컬럼: `협력회사명`, `사업자등록번호`, `기업규모`, 운영사별 인원·지원금액, `총 인원`, `총 지원금액`.

## 설치 및 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

### 의존성
- `streamlit`
- `pandas`
- `openpyxl`

> ⚠️ 현재 `requirements.txt`에 `streamlit`이 누락되어 있음. Streamlit Cloud는
> 기본 이미지에 포함되어 동작하지만, 로컬·devcontainer 환경에서는 추가 필요.

## 사용 흐름

1. 이번 달 1인당 지원금액 입력
2. 탑승 기록 파일(CSV/엑셀) 업로드
3. 정산 결과 미리보기 확인
4. **📥 완성된 정산 엑셀 파일 다운로드** 클릭
